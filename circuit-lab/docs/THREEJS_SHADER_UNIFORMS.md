# Three.js Custom Shader Uniforms Reference

## HeatMap Shader
- `uPowerDissipation`: `float` representing component power consumption in Watts.
- `uThresholdMax`: `float` threshold for thermal warning.

## LED Emission Shader
- `uCurrentLevel`: `float` simulated pin forward current (mA).
- `uEmissiveColor`: `vec3` color vector.
