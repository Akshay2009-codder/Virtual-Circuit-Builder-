# Release Notes - Virtual Circuit Builder v1.6.0

## What's New
- **Inductor & Op-Amp Engines**: Added transient inductor energy & op-amp saturation modeling.
- **3D Thermal Heat Maps**: Real-time component color shader reflecting power dissipation.
- **New Hardware Modules**: ESP32, A4988 Stepper Driver, SSD1306 OLED & ACS712 sensors.
- **UI Gesture Controller**: Added smooth pan/zoom canvas controls and auto-wire pathfinding.
