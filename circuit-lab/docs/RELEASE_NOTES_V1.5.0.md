# Release Notes - Virtual Circuit Builder v1.5.0

## What's New
- **Advanced Transient Solver**: Capacitance and diode V-I curve estimation.
- **3D Mesh Enhancements**: Dynamic LED emissive shaders, shadow mapping & wire arc physics.
- **New Component Catalog**: Rotary Encoders, RGB LEDs, DIP switches, Zener & Schottky diodes.
- **UI Improvements**: Keyboard shortcut manager, magnetic snap cursors, high-contrast dark theme.
