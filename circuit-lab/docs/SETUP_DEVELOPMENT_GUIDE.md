# Development Environment Setup Guide

## Quick Start
1. **Frontend (Vite + React)**:
   ```bash
   cd circuit-lab/frontend
   npm install
   npm run dev
   ```

2. **Backend (Flask + SQLite)**:
   ```bash
   cd circuit-lab/backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python app.py
   ```
