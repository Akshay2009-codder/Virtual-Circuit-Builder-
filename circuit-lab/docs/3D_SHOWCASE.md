# CircuitLab 3D Showcase & Community Repository

This document details the interactive 3D circuit showcase and preview capabilities in CircuitLab.

## Features
1. **Zero-Download 3D Previews**: Interactive orbiting 3D circuit previews embedded directly in the community cards.
2. **In-Modal Simulation & Testing**: Test-run circuits directly inside the 3D inspection modal without opening the builder.
3. **Interactive Control Elements**: SPST toggle switches and controls can be clicked in real time to simulate on/off states in 3D.
4. **Component Bill of Materials (BOM)**: Collapsible sidebar detailing all nodes, default values, and terminal counts.
5. **Direct Cloning**: 1-click clone action loading schematic state into the 3D Builder workspace.
